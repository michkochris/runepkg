Runepkg Unshielding & Absolute Tooling Independence Implementation Plan
This implementation plan establishes the definitive architectural ledger and roadmap for runepkg. It captures the approved new direction—combining Debian package structures and archive conventions as raw material with Cross Linux From Scratch (CLFS) cross-building discipline and the robust, minimal rescue spirit of Damn Small Linux (DSL)—while documenting all unshielding modifications and absolute tooling independence extensions.
User Review Required
Important
Done Deal / New Direction: As confirmed, all defensive host protections, core glibc live-root mutation checks, and host package pruning are permanently removed and decoupled. Runepkg operates as an unhindered, direct-mutation deployment engine.
•
Direct Live-Root Mutation: / and core system packages (e.g., libc6) can now be mutated directly without host restriction.
•
Dynamic Linker Anchoring: The Psychic subsystem ensures robust loader symlink anchoring (ld-linux-x86-64.so.2) across lib/ and usr/lib/.
•
Uniform Dependency Resolution: Full minimal dependency trees (libc6, libgcc-s1, libmagic, etc.) are resolved and pulled uniformly rather than pruned against host-installed packages.
