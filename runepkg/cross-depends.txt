This breakdown maps out the entire path from CLI parsing (runepkg_cli.c, runas in runepkg_runas.cpp) through C/C++ FFI bridges (runepkg_handle.c), graph traversal (runepkg_resolver.cpp), and repository batch downloads (runepkg_network.cpp).

To turn this into a real cross-depends (and resolve-cross-tree) command that matches how build-depends already works—including printing a split Host Cross-Toolchain (PATH / host arch) + Target Sysroot (runes_graph.bin / ma_config.sysroot) tree and generating copy-pasteable install commands—here is the exact wiring plan across those layers:

Where Each Piece of cross-depends Fits
CLI Routing (runepkg_cli.c & runepkg_runas.cpp)

Add cross-depends / resolve-cross-tree alongside build-depends / resolve-build-tree in runepkg_cli.c (and runas cross-depends <pkg> in runepkg_runas.cpp), passing --target (g_target_arch) through to the handler.

FFI Bridge (runepkg_handle.c & runepkg_cpp_ffi.h)

Expose runepkg_resolver_dump_cross_tree(const char *pkg_name, const char *target_arch) and call it from handle_resolve_cross_tree(const char *pkg_name).

Graph & Tree Solver (runepkg_resolver.cpp)

Call DebianMultiArchEngine::configure_multiarch(target_arch) so you have deb_build_arch, deb_build_triplet, deb_host_arch, deb_host_triplet, sysroot, and is_cross_compiling.

Host branch: Check required host cross-toolchain binaries in PATH (<deb_host_triplet>-gcc, <deb_host_triplet>-g++, <deb_host_triplet>-ld, <deb_host_triplet>-ar) and map them to host cross-compiler packages (gcc-<triplet>, g++-<triplet>, binutils-<triplet>).

Target branch: Reuse resolve_tree_multiple / dump_node_recursive (ResolveMode::MODE_BUILD) for the target arch/sysroot dependencies, filtering out pure host build tools where appropriate (DependencyFilter::is_host_build_tool).

Output: Print the unified [tree] visualization plus two clean one-liners—one for missing host cross-toolchain packages and one for runepkg --target=<arch>:<triplet> -i ... on the target sysroot.

Optional Batch Download (runepkg_network.cpp)

Mirror runepkg_repo_build_depends_download_multiple if you also want download-cross-depends to fetch target .debs into the target arch/sysroot cache.
