Here is an implementation plan and technical blueprint structured specifically for consumption by Android Studio / Gemini or an automated coding assistant.Architecture Blueprint: runepkg Destructible Cross-Toolchain Engine1. System OverviewTransform runepkg into a profile-driven, destructible cross-compilation engine that orchestrates:Stage 1 (Bootstrap / Blanket): Builds minimal host tools (/crosstools) and target sysroot (/mnt/clfs) for a chosen target profile.Context Switching (runepkg switch): Sets/resets active target environment state for subsequent builds.Stage 2 (Debian Packaging): Cross-compiles Debian source packages against /mnt/clfs and splits them into .deb artifacts via buildpkg-split.2. Target Profile SpecificationTarget definitions live in a structured configuration directory (e.g., /etc/runepkg/targets/<target>.conf or embedded assets).File Format: /etc/runepkg/targets/arm-uclibc.confIni, TOML[Target]
name = arm-uclibc
arch = arm
subarch = armv7-a
abi = eabi
float = hard
libc = uclibc
triplet = arm-unknown-linux-uclibceabi
deb_host_arch = armhf

[Paths]
sysroot = /mnt/clfs
crosstools = /crosstools
cross_bin = /crosstools/bin

[Environment]
CC = arm-unknown-linux-uclibceabi-gcc
CXX = arm-unknown-linux-uclibceabi-g++
LD = arm-unknown-linux-uclibceabi-ld
AR = arm-unknown-linux-uclibceabi-ar
RANLIB = arm-unknown-linux-uclibceabi-ranlib
STRIP = arm-unknown-linux-uclibceabi-strip
READELF = arm-unknown-linux-uclibceabi-readelf
PKG_CONFIG_SYSROOT_DIR = /mnt/clfs
PKG_CONFIG_LIBDIR = /mnt/clfs/usr/lib/pkgconfig:/mnt/clfs/usr/share/pkgconfig

4. Implementation Details by CommandModule A: runepkg switchObjective: Maintain a single, ephemeral target context across shell sessions without permanent system pollution.State File: /var/lib/runepkg/active_target.env (or /tmp/runepkg_active.env).Logic:runepkg switch <profile>: Reads /etc/runepkg/targets/<profile>.conf, validates its presence, and atomically writes the key-value pairs to active_target.env.runepkg switch --reset (or native): Unlinks active_target.env.runepkg switch --env: Outputs shell export KEY=VALUE statements for direct eval: eval $(runepkg switch --env).Module B: runepkg build-toolchain --target=<profile> [pkg]Objective: Bootstrap the Stage 1 destructible toolchain into /crosstools and /mnt/clfs.Execution Order:Sanity Check: Check permissions for /crosstools and /mnt/clfs (prompt or create if missing).Stage 1A (Host Tools): Cross-binutils compiled targeting ${TRIPLET} to ${CROSS_BIN}.Stage 1B (GCC Bootstrap): Minimal static C-only compiler (--without-headers --with-newlib --disable-shared).Stage 1C (Target Headers & Libc): Extract Linux kernel headers to ${SYSROOT}/usr/include; build and install libc (uclibc-ng / musl) into ${SYSROOT}/usr/lib and ${SYSROOT}/usr/include.Stage 1D (GCC Final): Full cross C/C++ compiler installed into ${CROSS_BIN}.Optional Target Package: If [pkg] was passed, immediately invoke runepkg switch <profile> and trigger runepkg buildpkg-split <pkg>.Module C: runepkg buildpkg-split <pkg> (Stage 2)Objective: Build standard Debian source code against the active target sysroot and emit split binary .deb packages.Build Phase:Load active_target.env. If not present, default to host/native.Unpack source directory and locate debian/rules or standard build scripts.Set DESTDIR=$(mktemp -d /tmp/runepkg-build-XXXXXX)/dest.Invoke build passing cross environment (CC, CXX, PKG_CONFIG_SYSROOT_DIR, DEB_HOST_ARCH).ELF Inspection & Metadata Generation:Run ${READELF} -d on all compiled ELF binaries inside ${DESTDIR}.Parse DT_NEEDED dynamic tags to detect runtime library dependencies.Synthesize the debian/control file for each sub-package:Runtime package (pkg_*.deb): Contains /usr/bin, /usr/sbin, /usr/share, plus autogenerated Depends: <libs>.Development package (pkg-dev_*.deb): Contains /usr/include, /usr/lib/*.a, /usr/lib/pkgconfig.Packaging:Bundle each split directory into a valid ar-formatted .deb archive (debian-binary, control.tar.gz, data.tar.gz).Output .deb files to the current working directory.5. Suggested C Implementation Tasks for IDE Assistantsrc/profile.c / src/profile.h:Implement INI/Config parser to read /etc/runepkg/targets/*.conf.Implement profile_load(), profile_set_active(), and profile_clear_active().src/env.c / src/env.h:Implement environment variable injector using setenv() / execve() wrapper to pass target variables cleanly to subprocess builds.src/elf_deps.c / src/elf_deps.h:Implement parser for readelf -d output or direct ELF header parsing to resolve dynamic shared object dependencies (DT_NEEDED).src/cmd_build_toolchain.c:Implement step-runner sequence for Stage 1 (binutils $\rightarrow$ gcc-boot $\rightarrow$ headers/libc $\rightarrow$ gcc-final).src/cmd_switch.c:Implement CLI handler for runepkg switch.
