Signal Safety (Async-Signal-Safe Self-Pipe Pattern)

static void fsm_signal_handler(int sig) {
    int saved_errno = errno;
    unsigned char b = (unsigned char)sig;
    if (g_active_tx_ctx && g_active_tx_ctx->sig_pipe[1] >= 0) {
        ssize_t n = write(g_active_tx_ctx->sig_pipe[1], &b, 1);
        (void)n;

    errno = saved_errno;
}
This is correct. You avoid the common pitfall of calling non-async-safe functions (malloc, fflush, unlink) inside the handler. The signal is written to a pipe and processed during normal execution flow, not inside the handler. This is how production systems do it (systemd, OpenSSH).
